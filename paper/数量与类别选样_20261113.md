# 数量与类别选样：当前定义

更新：2026-11-15。当前整合目录规则详见[攻击训练信息隔离与预算](攻击训练隔离与预算_20261115.md)。

- rate与vs_number生成时必须且只能指定一个。
- rate按注入前约80%的非测试训练图节点总数计算，不只按有标签训练索引计算。该训练图包含有标签、验证和未标注节点。
- Cora训练图2167个节点，rate=3给出65个过滤前候选，不是此前的16个或81个。
- vs_number显式指定过滤前候选数量，--vs-number为同义别名。
- class-sampling默认random；uneven按seed为原始类别分配不同数量。
- 两种选样方式都先选位置、再滤去原标签等于target的位置，不补选；本次默认random/seed10选65个，实际54组。
- 所有选样、过滤及生成器训练都只在压缩的训练子图范围内进行。
- 训练图预算、过滤数、实际组数和原类别计数分别保存，不能将预算直接写成过滤后实际数量。

```text
uv run --locked --extra cu118 python run_attack.py --dataset Cora --attack UGBA --rate 3 --seed 10 --output-root outputs/strict_train_graph_rate3 --device cuda:0
```

不均匀选样增加`--class-sampling uneven`；显式数量用`--vs_number 65`替换`--rate 3`。
