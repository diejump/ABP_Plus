## 5. 参数说明

| 参数 | 默认值 | 意义 |
|---|---:|---|
| hidden | 32 | 公共最终分类器宽度，优化版普通模型和同骨架复核模型均采用该值 |
| epochs | 200 | 公共最终分类轮数；优化版两个分类模型的原fit均使用该值 |
| learn-recover-epochs | 跟随epochs | 优化版恢复阶段轮数，0为取消恢复；显式覆盖单独记录 |
| learn-negative-weight | 3.0 | 错误标签约束损失权重 |
| learn-min-branch | 2 | 需要复核的最小无训练节点分支大小 |
| learn-hidden | 32 | 教师扩展的固定GCN教师宽度 |
| learn-epochs | 200 | 教师GCN训练轮数 |
| learn-confidence | 0.8 | 恢复候选监督所需教师置信度 |
| learn-rule | risk | 类别集中风险规则；其他选项为学习消融 |
| rate | 无 | 注入前约80%的非测试训练图节点百分比，包含其有标签、验证和未标注节点；与vs_number二选一 |
| vs_number | 无 | 显式过滤前选样预算，与rate二选一 |
| class-sampling | random | 默认随机；显式uneven为原始类别不均匀选样 |

命令行参数前面加两个连字符，例如`--hidden 32`。人工运行可修改src/config.py和run_study.py中的default；数量两项中必须有且仅有一项非None。

epochs=200且恢复未单独指定时，双模型的普通模型fit200轮、复核模型fit200轮，再恢复200轮；不是所有阶段合计200轮。教师扩展额外训练GCN教师200轮，完整计时包含全部阶段。

旧优化目录的模型参数可显式设置为：

```text
--hidden 64 --epochs 400 --learn-recover-epochs 400 --learn-epochs 200
```

这只恢复模型参数，不恢复旧的全图比例预算、旧过滤规则或旧性能结果。

## 6. 预算、继续运行与重载

默认random；两种模式都先选后过滤原目标类，不补选。Cora非测试训练图2167个节点，rate=3给出预算65个，实际组数可能减少。本次seed10默认random过滤11个，实际54组。显式数量用`--vs_number 65`替换`--rate 3`，不均匀模式增加`--class-sampling uneven`。

相同参数继续已完成运行时，在原命令末尾加`--resume`；改变参数使用新输出目录。复制的outputs为历史保留，记录中可能含原项目绝对路径，不应直接对整份历史结果执行resume来代替新实验。

单独重载教师扩展模型：

```text
uv run --locked --extra cu118 python run_defense.py --bundle outputs/integrated_run/data/Cora/UGBA/seed10 --checkpoint outputs/integrated_run/runs/Cora/UGBA/seed10/GCN/abp_assisted/model.pt --output-root outputs/reload_assisted --device cuda:0
```

重载会恢复全部必需辅助模型，不重新训练。本次只对真实Cora做短轮次接口检查和保存重载，不将短训练指标作为科研性能结论。
