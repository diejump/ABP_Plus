# 受控参数与作者原设对照

日期：2026-11-15。范围：`D:/GNNAttackReaserch/abp`。本次只调整最终分类器配置及DShield分类阶段轮数，不改攻击、预算、标签条件、剪边/识别规则和其他辅助训练设置。

## 1. 本次采用的最终分类器配置

最终模型统一为隐藏宽度32、训练或恢复200轮、学习率0.01、权重衰减0.0005、dropout 0.5。GCN、GAT、GraphSAGE仍分别使用原有作者实现；已有两层结构、GAT的8头保持原样，GAT宽度32表示每头宽度。

| 方法/攻击 | 作者原设或原项目设置 | 本次最终配置 |
|---|---|---|
| 无防御、ABP（项目自设） | RIGBD骨架，宽度64、400轮 | 宽度32、200轮 |
| RIGBD | 最终宽度64、恢复400轮 | 最终宽度32、恢复200轮 |
| LoSplit/GTA | Cora宽度32、恢复200轮，lr=0.01 | 保持 |
| LoSplit/UGBA | Cora宽度32、恢复200轮，lr=0.01 | 保持 |
| LoSplit/DPGBA | Cora公开脚本宽度32、恢复200轮，lr=0.015 | 宽度32、恢复200轮，lr=0.01 |
| MAD/三种攻击 | 宽度32、每次最终训练200轮 | 保持，原5次内部重复保留 |
| Prune/GTA、UGBA | 宽度32、200轮 | 保持 |
| Prune/DPGBA | 对应入口默认宽度512、200轮 | 宽度32、200轮 |
| DShield | 宽度32，分类阶段200或500轮 | 宽度32，分类阶段统一200轮 |

“作者原设”区分入口默认值和公开Cora脚本覆盖，不将任意默认称为该组合最优值。ABP的64/400来自本项目公共参数，并非作者普通训练入口的原始默认。

本次不替换Prune的LoSplit模型实现，也不把各作者不同的选模/恢复规则改成同一个训练器。因此这是最终主要超参数受控，不宣称所有骨架内部细节已经完全相同。

## 3. DShield的改动边界

| 阶段 | Cora/UGBA：原值→当前 | Cora/GTA、DPGBA：原入口默认→当前 |
|---|---:|---:|
| 准备分类器轮数 | 200→200 | 200→200 |
| 预训练轮数 | 400→400 | 1000→1000 |
| 分类阶段轮数 | 200→200 | 500→200 |
| 微调轮数 | 400→400 | 500→500 |
| 分类轮次 | 1→1 | 100→100 |

没有把100个分类轮次缩减为1。DShield内部多阶段循环并不能简单相加成一次普通训练轮数。

## 4. 参数路由与溯源

公共`--hidden/--epochs/--lr/--weight-decay/--dropout`默认改为32/200/0.01/0.0005/0.5，并用于最终分类器。作者参数表`configs/author_parameters.json`保留原值；作者辅助模型仍读取原值，最终阶段通过单独参数视图构造模型及调用fit。

公共最终参数的优先级高于作者覆盖JSON中的同类字段；改变最终配置应使用公共参数。作者JSON仍可覆盖辅助评分轮数、划分参数和专属阈值。DShield的准备/最终分类器共享作者同一架构，因此共享宽度；本次默认32等于原值，准备轮数保持200。

例如RIGBD的原`epochs=1000`继续用于评分，最终恢复使用单独的最终轮数字段，避免“改了评分轮数、最终仍400”的错误。LoSplit和MAD同样只在最终分类器调用处切换参数视图。

每次运行保存作者辅助参数与最终分类器参数；受控运行采用新的协议标识，旧结果、旧检查点和原作者源文件保留。复用数据时使用相同样本包；重新运行模型请选择新输出目录。

本次只做配置、调用路由和源码完整性检查，不运行完整性能实验，也不把原CA/ASR表改写成新参数结果。
